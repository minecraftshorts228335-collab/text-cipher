# Текстовый цензор на Python (Text Censor)

Учебный проект на Python, который ищет заданные слова в тексте, скрывает их с помощью шифра Цезаря и формирует детальный отчёт о совпадениях.

## Возможности
- **Шифрование:** Использует классический шифр Цезаря со сдвигом на 3 символа.
- **Точный поиск:** Проверяет границы слов, благодаря чему короткие слова (например, `art`) не заменяются внутри других слов (например, `artist`).
- **Сохранение контекста:** Корректно сохраняет пробелы, знаки препинания, регистр остальных букв и кириллицу.
- **Отчёт:** Выводит количество вхождений каждого слова из списка (включая нулевые значения) и общую сумму найденных совпадений.

## Используемые технологии
